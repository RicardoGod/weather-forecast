# Starter code — integrar no projeto Android

Este starter contém os modelos e os pontos de entrada da UI da Missão 01. Cria um projeto Empty Activity com Jetpack Compose no Android Studio e copia os ficheiros para o package indicado, ou integra-os no projeto fornecido pelo mentor.

Não inclui Gradle Wrapper nem versões fixas do Android Gradle Plugin/SDK para evitar impor versões que possam não corresponder ao ambiente de formação. O mentor deve fornecer o projeto Android base já validado.
