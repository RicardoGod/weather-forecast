# Missão 04 — Estados e resiliência

## Objetivo
Tornar a experiência clara quando a aplicação está a carregar, não encontra uma cidade ou não consegue contactar a API.

## Estados obrigatórios
- Loading.
- Success.
- Empty / no results.
- Error com possibilidade de tentar novamente.

## Critérios
- [ ] O indicador de loading aparece durante o pedido.
- [ ] O ecrã não fica bloqueado.
- [ ] Erros têm uma mensagem compreensível.
- [ ] Retry volta a executar o pedido.
- [ ] Os dados anteriores não desaparecem sem necessidade durante uma atualização.
