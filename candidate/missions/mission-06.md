# Missão 06 — Guardar cidades favoritas

## Objetivo
Permitir guardar e remover cidades favoritas e mantê-las após fechar a aplicação.

## Requisitos
- Adicionar/remover favorito.
- Lista de favoritos.
- Persistência local com Room.
- Exposição de alterações com Flow.
- Ao reabrir a aplicação, favoritos continuam disponíveis.

## Critérios
- [ ] Favoritos persistem após reinício.
- [ ] Não existem duplicados para a mesma localização.
- [ ] A UI reage a alterações na base de dados.
- [ ] A camada de persistência não é chamada diretamente pelos composables.
