# Missão 02 — Procurar uma cidade

## Objetivo
Adicionar pesquisa de cidade sem introduzir ainda uma chamada de rede. Usa um conjunto pequeno de cidades locais/fictícias.

## Requisitos
- Campo de pesquisa com ação de limpar.
- Lista de resultados.
- Selecionar uma cidade atualiza o ecrã meteorológico.
- Estado vazio quando não existem resultados.
- A pesquisa deve ignorar maiúsculas/minúsculas.

## Conceitos
State hoisting, eventos, `remember`/`mutableStateOf` ou abordagem equivalente, listas e funções Kotlin.

## Critérios
- [ ] Pesquisa funciona com correspondência parcial.
- [ ] Selecionar resultado atualiza a cidade apresentada.
- [ ] Estado vazio é compreensível.
- [ ] A lógica de filtragem não está misturada com o layout.
