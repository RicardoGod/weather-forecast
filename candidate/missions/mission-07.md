# Missão 07 — Testar e consolidar

## Objetivo
Adicionar testes que protejam os comportamentos principais.

## Testes sugeridos
- Conversão de weather code para descrição/ícone.
- Mapeamento de DTO para modelo de domínio.
- Repository com fake data source.
- ViewModel: loading, success e error.
- UI: cidade, temperatura, previsão e interação de favoritos.

## Critérios
- [ ] Testes unitários não dependem da rede real.
- [ ] UI tests usam semantics e testTags apenas onde necessário.
- [ ] Falhas são reproduzíveis.
- [ ] O README explica como executar a aplicação e os testes.
